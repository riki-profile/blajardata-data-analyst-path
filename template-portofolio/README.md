# Template Portofolio

Setiap modul menghasilkan **satu repository portofolio sendiri**, jadi peserta yang hanya mengambil satu modul tetap pulang dengan portofolio yang lengkap. Peserta jalur penuh membangun ketiganya, lalu menghubungkannya lewat README profil GitHub.

| Modul | Sesi | Repository | Template |
| --- | --- | --- | --- |
| SQL | 1–4 | `thelook-sql-analysis` | [thelook-sql-analysis/](thelook-sql-analysis/) |
| Python | 5–9 (+ studi kasus sesi 12 untuk jalur penuh) | `thelook-python-analysis` | [thelook-python-analysis/](thelook-python-analysis/) |
| Power BI | 10–11 | `thelook-powerbi-dashboard` | [thelook-powerbi-dashboard/](thelook-powerbi-dashboard/) |
| Jalur penuh | 13 | README profil GitHub (repo bernama sama dengan username) | [profil-github/](profil-github/) |

**Kamu tidak perlu menyalin template sekaligus.** Repo dibuat di sesi pertama setiap modul, lalu diisi setiap sesi:

| Sesi | Yang ditambahkan |
| --- | --- |
| 2 | Repo `thelook-sql-analysis`; `sql/01_basics.sql`, `sql/02_aggregation.sql` |
| 3 | `sql/03_joins.sql` |
| 4 | `sql/04_dates_case_cte.sql` + **README SQL** (proyek SQL) |
| 5 | Repo `thelook-python-analysis`; `notebooks/05_python_basics.ipynb` |
| 6–8 | `notebooks/06_...` sampai `08_...`; grafik di `images/` |
| 9 | `notebooks/09_...` + **README Python** (3 temuan) |
| 10 | Repo `thelook-powerbi-dashboard`; file dashboard + screenshot |
| 11 | Dashboard final + **README Power BI** |
| 12 | *(jalur penuh)* `my_question/` di repo Python + bagian studi kasus di README Python |
| 13 | *(jalur penuh)* README profil GitHub yang menghubungkan ketiga repo; pin ketiganya |

File `README.md` di setiap subfolder template adalah contoh isi singkat untuk folder itu (opsional).
